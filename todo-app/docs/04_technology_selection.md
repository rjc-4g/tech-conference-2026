# Step4：技術選定

## 採用技術

| 分類 | 技術 |
|---|---|
| フロントエンド | React + TypeScript |
| ビルドツール | Vite |
| UI | Tailwind CSS / shadcn-ui想定 |
| バックエンド | Java 21 + Spring Boot 3.5系 |
| DB | SQLite |
| API | REST API |
| 開発環境 | Docker Compose |
| テスト | Vitest / React Testing Library / JUnit |

## 採用理由

- AIADで実装指示しやすい
- CRUDアプリとの相性がよい
- ユーザのJava/React経験を活かしやすい
- ローカルで検証しやすい
- AIDDとの比較がしやすい
