# 要件定義

## 目的

- AI開発の​技術検証
- AIDDと​AIADの​比較

## 対象ユーザ

- ​一般ユーザ​（汎用的な​アプリ）​

## 解決したい​課題

- タスクを​登録して​満足してしまう
- 優先順位が​決められない
- 期限切れタスクに​気づけない​

## 最小機能

- TODO登録, 一覧, 編集, 削除, 完了
- ​今​日やる​TODOだけを​表示
- タスクの​階層化​（親タスク・子タスク）​
- タスクの​カテゴリ分け。​カテゴリを​つけて​カテゴリごとに​みられるように。​
- タスクの​検索機能
- タスクの​進捗​（バー）​
- ​並べ替え​（ドラッグで​順序入れ替え）​
- タスクを​登録して​満足してしまう​ことを​抑止する​機能

## 画面構成

- ​一覧​画面 + モーダル登録

## データ項目

- 機能を​実現する​ために​必要な​もの​
